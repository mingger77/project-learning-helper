# project-doc-profile（PROFILE.md 撰写规范）

定位：**学习者画像**——「我是谁、我要什么、怎么讲我才听得懂」。与 `MAP.md` **同等重要**：MAP 决定"先学什么"，PROFILE 决定"讲多深、给几层提示、Lab 拆多细"。

由 `/profile` 生成与增量更新；其余时间**只读**。

## 生成规则

- 画像缺失时不得臆造：要么先跑 `/profile`，要么用默认值（中等 / 看懂并上手 / 例子驱动 / 严格度=达标即止）并在 §4 标注「假设」。
- 未回答项一律给默认值 + 标「假设」，随时可反悔重写。
- 前置自检只列**本项目 Lab 真会用到的概念**（由 `/read` 依画像裁剪），不是通用清单。
- **禁止编造网址**：每条检验给真实检索到的官方入口并标验证状态；没有联网工具时标「未验证」并给出确信的文档入口。

## 结构模板

```markdown
# PROFILE.md —— <项目名> 学习者画像

> 由 `/profile` 采集；未回答项以默认值补齐并标注「假设」。画像变化时**追加**「更新于」小节，不删历史。

## 1. 基本信息

- 编程水平：<没写过代码 / 学过一门语言入门 / 能独立写小项目 / 熟悉该语言栈>
- 相关经验：<语言、框架、领域词汇的掌握情况>
- 学习目标：<看懂 / 能上手改 / 能复现 / 能讲给别人>
- 希望学到的知识：<具体主题>
- 文档偏好：<语言 / 篇幅（精简·标准·详尽）/ 风格（概念·例子·任务驱动）>
- 学习方式偏好：<先读后做 / 边读边做 / 任务驱动>

## 2. 实验与评分偏好

- 严格度：<达标即止 / 尽量满分>
- 规则检查：<要 / 不要>
- Lab 粒度：<小步快跑 / 大实验>
- 跑分节奏：<每改必跑 / 关键节点跑>
- 卡住时的偏好：<先给提示梯度 / 直接讲原理>

## 3. 前置自检（学本项目前需要具备的概念）

| 知识点 | 我已具备？ | 检验（官方入口 / 小测） | 缺失时的去处 |
|---|---|---|---|
| <概念/工具/术语> | 是 / 否 / 不确定 | <链接（标来源与验证状态）或一道复述题> | <others/项目解析.md 概念速查 / LAB.md 背景 / 官方文档> |

## 4. 假设与默认值

- <未回答项 → 默认值，标注「假设」>
```

## 稳定锚点（`/read`、`/lab` 与工具依赖，勿改格式）

- 一级分区固定为 `## 1. 基本信息`、`## 2. 实验与评分偏好`、`## 3. 前置自检`、`## 4. 假设与默认值`；
- §2 的键名固定：`严格度` / `规则检查` / `Lab 粒度` / `跑分节奏` / `卡住时的偏好`（值可改，键名不改）；
- §3 表格列固定：`知识点 | 我已具备？ | 检验 | 缺失时的去处`；
- 增量更新一律新增 `## 更新于 <YYYY-MM-DD>` 小节，**不修改历史小节**。

## 规则

- 画像只影响**讲解深度、提示层数、Lab 粒度、阈值建议**，**不影响** Lab 的规则与评分口径（规则对所有学习者一致）。
- `/profile` 可重复执行：每次追加「更新于」小节记录变化；当前有效值以最新小节为准。
- 跨项目复用：把同一份 `PROFILE.md` 复制到新项目；全局默认（`learning_plan/PROFILE.md`）不在本版本范围。
- 画像与 `MAP.md` 的 Lab 划分必须一致：画像说"没写过代码"，就不该排一个要求"独立设计架构"的 Lab；不一致时先调 Lab 粒度。
