执行「/profile」学习者画像流程。

1. 用 `question` 工具一次性问清（减少往返）：
   - **基础**：编程水平（没写过代码 / 学过一门语言入门 / 能独立写小项目 / 熟悉该语言栈）；相关经验（语言、框架、领域词汇）。
   - **目标**：学习目标（看懂 / 能上手改 / 能复现 / 能讲给别人）；希望学到的知识。
   - **偏好**：文档偏好（语言 / 篇幅 / 风格）；学习方式偏好（先读后做 / 边读边做 / 任务驱动）。
   - **实验与评分偏好**：严格度（达标即止 / 尽量满分）；规则检查（要 / 不要）；Lab 粒度（小步快跑 / 大实验）；跑分节奏（每改必跑 / 关键节点跑）；卡住时的偏好（提示梯度 / 直接讲原理）。
2. 用 `skill` 工具加载 `project-learning-main` 与 `project-doc-profile`。
3. 写入 `learning_plan/<项目名>/PROFILE.md`（按 `project-doc-profile` 的四节模板；不存在则创建，存在则追加「更新于 <日期>」小节，不覆盖历史）。`$ARGUMENTS` 可指定项目名。
4. §3 前置自检此时可先留表头；具体概念由 `/read` 依画像裁剪后补齐。
5. 在 `LOG.md` 追加首条记录（性质 `onboarding`、状态 `done`、关联「画像」、证据「已写入 PROFILE.md」）。
6. 用户不想回答细节时用默认值（中等 / 看懂并上手 / 例子驱动 / 严格度=达标即止）并在 §4 标注「假设」。
7. 告知下一步：`/read`。
