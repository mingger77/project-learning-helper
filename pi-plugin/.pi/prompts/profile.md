---
description: 采集/更新学习者画像与前置自检（编程水平·目标·偏好·实验评分偏好）→ PROFILE.md
argument-hint: "[项目名]"
---
进入项目学习模式，执行「/profile」学习者画像流程。

1. 调用 `learning_profile` 工具（有 UI 时弹向导；无 UI 时在对话里逐项提问）。
   需要采集：基础（编程水平 / 相关经验）、目标（学习目标 / 希望学到的知识）、偏好（文档语言·篇幅·风格 / 学习方式）、**实验与评分偏好**（严格度 / 规则检查 / Lab 粒度 / 跑分节奏 / 卡住时的偏好）、后续操作方式（保持默认 / 特定要求）。
2. 用 `read` 加载 `project-learning-main` 与 `project-doc-profile` 技能。
3. 写入 `learning_plan/${1:-<项目名>}/PROFILE.md`（按 `project-doc-profile` 的四节模板；不存在则创建，存在则追加「更新于 <日期>」小节，不覆盖历史）。
4. 前置自检（§3）此时可先留表头；具体概念由 `/read` 依画像裁剪后补齐。
5. 用 `learning_log` 追加首条记录：性质 `onboarding`、状态 `done`、关联「画像」、证据「已写入 PROFILE.md」。
6. 用户不想回答细节时用默认值（中等 / 看懂并上手 / 例子驱动 / 严格度=达标即止）并在 §4 标注「假设」。
7. 告知下一步：执行 `/read` 建立地图、前置自检与可实验点。
